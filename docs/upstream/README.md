# Upstream wastebin documents

These files are wastebin's own documents, copied from
[matze/wastebin](https://github.com/matze/wastebin) at commit `c0ec968`. They
are kept for reference and are not maintained for Zpaste.

| File | Content |
| --- | --- |
| [WASTEBIN-README.md](WASTEBIN-README.md) | wastebin's README: configuration variables, HTTP API, `wastebin-ctl`, client snippets |
| [CHANGELOG.md](CHANGELOG.md) | wastebin's release history up to 3.9.0 and its unreleased changes |
| [CONTRIBUTING.md](CONTRIBUTING.md) | wastebin's contribution guide; the upstream file is empty |

While Zpaste behaves like upstream, the configuration and API sections of
`WASTEBIN-README.md` describe Zpaste too, with two differences: the server
executable is `zpaste`, and Zpaste publishes no binaries or images under the
upstream names (`quxfoo/wastebin`, the matze/wastebin releases).

These documents drift from Zpaste on purpose as Zpaste changes. The current
Zpaste documentation is the [README](../../README.md) at the repository root.
